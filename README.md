# Job-Listings-Scraper
Scraper de ofertas de empleo construido con Python, Requests y BeautifulSoup, con una interfaz de terminal (TUI) hecha con Textual que muestra los resultados en tiempo real. Proyecto del desafío Job Listings Scraper de roadmap.sh. Extrae título, empresa, ubicación y URL de cada oferta desde Fake Python Jobs.
